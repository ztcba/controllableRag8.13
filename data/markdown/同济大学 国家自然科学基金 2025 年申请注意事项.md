# 国家自然科学基金2025年申请注意事项
**发布单位**：同济大学科研管理部  
**发布时间**：2025年1月  

## 重要提醒
1. **撰写提纲新增要求**：同年以不同专业技术职务（职称）申请或参与申请科学基金项目的人员，需在申请书“其他需要说明的情况”中列明申请/参与申请项目情况，并详细说明原因。**务必使用2025年版撰写提纲**，避免因缺项被初筛。
2. **科学部资助要求前置**：任何项目类型申请前，均需查看《科学部资助领域和注意事项》，明确科学部总体资助原则、申请注意事项及学科资助范围。
3. **全面无纸化申请**：
   - 申请书需为2025年正式版本，封面有水印“2025NSFC”；
   - 网上提交的电子版须为正式版本，**严禁出现“草稿”字样**；
   - 专家回避信息需在网上填写。


## 一、2025年申请须知的内容
### （一）申请规定新增内容
1. **职称申报说明**：同年以不同专业技术职务（职称）申请/参与申请项目的人员，需在申请书“其他需要说明的情况”中列明项目情况及原因（重点关注撰写提纲变化）。
2. **同年多项目申报说明**：申请人同年申请不同科学基金项目时，需在申请书中列明其他项目的“项目类型+项目名称”，并说明项目间区别与联系；已收到“不予受理”或“不予资助”决定的项目无需列出。
3. **不予受理情形补充**：申请人或主要参与者因违背科研诚信、科技伦理等行为，被禁止承担/参与财政性资金支持科技活动的，其申请将不予受理。
4. **限项政策调整**：
   - 试点项目：企业创新发展联合基金、“叶企孙”科学基金项目**申请时不计入**申请/承担项目总数，正式接收后计入；科研人员申请/承担同一名称的上述联合基金项目合计限1项。
   - 群体类项目：明确卓越研究群体项目（含原基础科学中心项目）、创新研究群体项目、国家杰出青年科学基金延续项目、合作创新研究群体的限项规定。
5. **预算说明调整**：2025年指南将“预算表”与“预算说明书”分开单独说明，需分别按要求编制。


### （二）申请人条件
#### 1. 基本条件
需同时满足以下两项要求：
- 具有承担基础研究课题或从事基础研究的经历；
- 具有高级专业技术职务（职称）、博士学位，或有2名同研究领域的高级专业技术职务（职称）人员推荐。

#### 2. 关键注意事项
| 条件类别 | 具体要求 |
|----------|----------|
| 博士学位 | 博士学位证书授予日期需在**2025年3月20日前**（仅答辩通过未获证书无效） |
| 专家推荐信 | 需使用2025年版模板，**每项内容必填**、专家亲笔签名后扫描上传；严禁两份推荐信为同一专家出具，上传后需二次核对文件正确性 |
| 依托单位非全职人员 | 需在申请书中如实填写“聘任岗位+聘任期限+每年在学校工作时间”（建议在“其他需要说明的情况”中补充）；聘任合同纸质版需存档；**所有非全职人员均需提供原单位同意函** |
| 非本校工作人员（无单位/单位非依托单位） | 仅可申请“面上项目”或“青年科学基金项目”；需如实填写工作单位信息；**与依托单位无聘用关系的境外人员，不得以此身份申请任何项目** |
| 联合培养博士后 | 建议以“兼职聘用”身份申报，并提供原单位同意函 |

#### 3. 特殊人群申报要求
| 人群类别 | 申报权限与要求 |
|----------|----------------|
| 在站博士后 | 可申请面上项目、青年科学基金项目；获资助后可变更依托单位 |
| 在职攻读研究生学位人员 | - 本校在职攻读：经导师同意可依托本校申请部分项目，需上传导师签字的同意函（用模板，纸质与电子版一致）；<br>- 非本校在职攻读：不可依托本校申报 |
| 受聘于依托单位的境外人员 | 不得同时以“境内申请人”和“境外合作者”（国际/地区合作研究项目外方合作者）两种身份申请项目；<br>境内身份项目负责人，在项目资助期满前不得作为境外合作者参与申请国际/地区合作研究项目 |


### （三）申请材料要求
#### 1. 基本规范
- 申请书需由申请人本人撰写，个人简历需规范填写；
- 需使用2025年版最新撰写提纲，严格按填报说明提供材料；
- 准确选择“资助类别”“亚类说明”“附注说明”（未要求选择的留空）；
- 需从“自由探索类基础研究”“目标导向类基础研究”中选择1项研究属性；
- 涉及科技伦理/科技安全（如生物安全、信息安全）的项目，需严格遵守国家法律法规及伦理准则。

#### 2. 申请代码选择
1. 尽量选择到**二级申请代码（4位数字）**；
2. 重点项目、联合基金项目等对申请代码有特殊要求的，需查阅《指南》相关项目部分；
3. 填写基本信息表时，需准确匹配“申请代码1+研究方向+关键词”；
4. 对申请代码有疑问的，需向相关科学部咨询。

#### 3. 主要参与者与简历
| 要求类别 | 具体规定 |
|----------|----------|
| 参与者列表 | 学生**不得列入**主要参与者表格，仅需在“总人数统计表”中填写学生人数；表格中列入的人员均需上传简历 |
| 简历采集 | 主要参与者简历需通过信息系统在线填写，由系统生成PDF版后上传；<br>- 需提前完成撰写，预留修改时间（形式审查发现简历问题需退回本人修改）；<br>- 必须使用**2025年版新生成简历**，严禁使用往年版本 |
| 代表性成果 | - 代表性论文：上传公开发表的全文PDF；<br>- 代表性专著：上传“封面+摘要+目录+版权页”的PDF扫描件 |
| 合作研究单位 | 参与者为外单位人员时，其所在单位视为合作研究单位（境外单位除外）；合作单位需具有独立法人资格，需在线准确填写单位信息 |

#### 4. 个人信息规范
- 申请人及主要参与者需使用**唯一身份证件**申请，姓名需与身份证件完全一致（字符需规范，避免错别字）；
- 具有高级专业技术职务（职称）的申请人/参与者，若存在以下情况，需在申请书中详细注明：
  1. 同年申请/参与申请项目的单位不一致；
  2. 与正在承担的科学基金项目单位不一致。

#### 5. “其他需要说明的情况”填写清单
需涵盖以下内容（如有）：
1. 高级职人员单位不一致的情况说明；
2. 研究内容已获其他渠道资助的，需说明“受资助情况+与本项目的区别与联系”（避免重复申请）；
3. 同年申请多个项目的，需列明其他项目“类型+名称”及项目间区别与联系；
4. 同年以不同职称申请/参与项目的，需列明项目情况及原因。

#### 6. 签字与确认
- 提交申请前，需征得主要参与者、合作单位对申请材料的同意；
- 项目获批后，申请人及主要参与者需在**纸质签字盖章页**亲笔签字；境外参与者无法签字的，需通过信件/传真提交签字纸质文件（说明同意参与及承担工作）；合作单位、依托单位需加盖公章（公章名称与申请书中单位名称一致）。


## 二、限项申请规定
### （一）一般性规定
1. 申请人同年仅可申请**1项同类型项目**（除外情形：重大研究计划集成/战略研究项目、专项项目中科技活动项目、国际/地区合作交流项目）；
2. 上年度获得以下项目资助的负责人，本年度不得申请同类型项目：
   - 面上项目、重点项目、重大项目、重大研究计划项目（不含集成/战略研究）；
   - 联合基金项目（同一名称）、地区科学基金项目。


### （二）申请和承担项目总数限制
#### 1. 核心限制规则
| 人员职称 | 项目总数限制（合计） | 特殊时间节点规定 |
|----------|----------------------|------------------|
| 高级职称 | 限2项（涵盖项目：面上、重点、重大、重大研究计划<不含集成/战略>、联合、青年、优青、杰青、重点国际合作、重大仪器、直接费用>200万元的组织间国际合作<仅限申请人/负责人>、创新研究群体<2025年起>、卓越创新研究群体、资助期>1年的原创探索计划/专项项目<科技活动项目除外>） | 2019年（含）前批准的参与项目不计入；2020年（含）后批准的项目（含负责人/参与者）计入 |
| 非高级职称 | “1+2”规则：<br>- 作为申请人/负责人：限1项；<br>- 作为主要参与者：限2项 | 2022年（含）前批准的参与项目不计入；2023年（含）后批准的项目（含负责人/参与者）计入；晋升高级职称后，原非高级职称参与的项目不计入 |

#### 2. 不计入总数的项目类型
- 数学天元基金项目；
- 直接费用≤200万元/项的组织间国际（地区）合作研究项目；
- 国际（地区）合作交流项目、重大研究计划集成/战略研究项目；
- 外国学者研究基金项目、合作创新研究团队项目；
- 专项项目中的科技活动项目、资助期限≤1年的其他项目；
- 指南特别说明不受总数限制的项目。


### （三）部分项目类型特殊限项
| 项目类型 | 特殊规定 |
|----------|----------|
| 国际（地区）合作类 | - 正在承担国际（地区）合作研究项目的负责人，不得再申请同类型项目；<br>- 同一组织间协议框架下的合作交流项目，申请/承担合计限1项 |
| 联合基金（企业创新发展/“叶企孙”） | 申请时不计入总数，正式接收后计入；有在研同名称项目（含申请人/参与者）的，不得再申请 |
| 优青、杰青 | 申请时不计入总数，正式接收后计入 |
| 原创探索计划项目 | 申请时不计入总数，获资助后计入（资助期≤1年除外）；同年仅可申请1项（含预申请） |
| 外国学者研究基金/合作创新团队 | 申请/承担合计限1项（申请人/负责人身份） |


### （四）国家科技计划项目联合限项
根据《科技部办公厅财政部办公厅自然科学基金委办公室关于进一步加强统筹国家科技计划项目立项管理工作的通知》，以下项目实施联合限项，科研人员同期申请/承担项目（课题）数**原则上≤2项**（申请当年资助期满的不计入）：

| 涉及项目类别 | 具体范围 |
|--------------|----------|
| 国家自然科学基金 | 重大项目（限负责人/课题负责人）、卓越创新研究群体（限学术带头人/骨干）、国家重大科研仪器研制项目（限部门推荐类负责人/高级职称参与者） |
| 其他国家科技计划 | 国家重点研发计划（不含青年科学家/科技型中小企业/国际合作类，限负责人/课题负责人）、科技创新2030-重大项目（不含青年科学家，限负责人/课题负责人） |

**额外限制**：高级职称人员申请/承担“国家重大科研仪器研制项目”+“国家重点研发计划‘基础科研条件与重大科学仪器设备研发’重点专项（科学仪器方向）”合计限1项。


## 三、预算编制要求
### （一）预算管理方式分类
| 管理方式 | 适用项目类型 | 编制要求 |
|----------|--------------|----------|
| 包干制 | 杰青、优青、青年科学基金项目、博士生项目 | 无需编制预算表及预算说明书，按“科学、合理、规范、有效”原则申请资助额度 |
| 预算制 | 除包干制外的其他项目 | 需编制《国家自然科学基金预算制项目预算表》及《预算说明书》；仅编报直接费用，间接费用由自然科学基金委统一核定 |

#### （二）直接费用三大科目说明
| 科目名称 | 定义与要求 |
|----------|------------|
| 设备费 | 用于购置/试制专用仪器、升级改造现有仪器、租赁外单位仪器的费用；<br>- 可列支计算类仪器设备及软件工具（**不含通用笔记本电脑**）；<br>- 严格控制购置，优先选择开放共享、自主研制、租赁，避免重复购置 |
| 业务费 | 包括：低值易耗品采购/运输/整理费、测试化验加工费、燃料动力费、出版/文献/知识产权事务费、会议/差旅/国际合作交流费等；<br>- 按支出大类测算说明 |
| 劳务费 | 用于支付研究生、博士后、访问学者、项目聘用人员（研究/科研辅助）的劳务性费用，及临时咨询专家费用；<br>- 咨询专家费用**不得支付给本项目研究/管理人员**；<br>- 聘用人员劳务费参照当地科学研究和技术服务业平均工资水平，社会保险补助、住房公积金纳入本科目 |

#### （三）预算说明书撰写要求（2025年新增明确要求）
需按科目逐一说明，核心要求如下：
1. **设备费**：
   - 说明支出必要性及测算合理性；
   - 单价≥50万元（含）的设备：补充“主要性能指标+主要技术参数”；
   - 单价<50万元的设备：按“购置费+试制改造费+租赁使用费”分类说明。
2. **业务费**：按“材料费、测试化验加工费、燃料动力费”等支出大类，说明基本测算依据。
3. **劳务费**：按人员类别，说明“承担任务必要性+工作时长+费用标准合理性”。
4. **合作研究外拨资金**：
   - 说明合作单位承担的研究任务及资金外拨情况；
   - 多个合作单位需逐一说明，外拨金额需重点标注。

#### （四）预算调整规则
项目获批后，在计划书填报阶段：
- 直接费用总额不得超过批准的直接费用预算总额；
- 各科目金额原则上不得超过申请书对应科目金额；
- 经预算评审的项目，需按评审意见调整。


## 四、科研诚信要求
### （一）个人信息真实性
1. 职称履历：需**详细列出各时间段对应的职称**，严禁“跳过中间职称仅填最高职称”或篡改信息；
2. 导师信息：申请人及参与者需如实填写“博士/硕士/博士后导师姓名”（系统生成的PDF简历中不再显示导师信息，需自行核对填写完整性，避免错填漏填）；
3. 学位与职称：
   - 学位信息需与证书一致，获得时间以证书日期为准；
   - 职称信息需为依托单位正式聘用职称（内聘职称需依托单位有相应评定资质），严禁伪造；
4. 无单位/单位非依托单位人员：需在基本信息表中如实填写工作单位，严禁伪造。


### （二）研究内容与成果真实性
1. 研究基础与内容：需如实填写，严禁弄虚作假、抄袭剽窃（包括但不限于学术观点、研究思路、方案、文字表述）；
2. 成果署名：
   - 论文、专利等成果需按发表时的真实情况列出所有作者（发明人/完成人），严禁篡改作者顺序；
   - 代表性论文需如实标注本人署名情况（如第一作者、通讯作者），严禁虚假标注；
3. 成果合法性：不得使用存在“伪造、篡改、抄袭、第三方代写代投、同行评议造假”等科研不端行为的成果；
4. 同行评述：需如实描述成果的同行评价，严禁虚构或夸大学术贡献；
5. 伦理审查：涉及人、实验动物或其他伦理风险的研究，需按国家/部门/单位要求通过伦理审查；
6. 重复申请禁止：
   - 不得将相同/相近研究内容，以不同项目类型、不同申请人、不同依托单位重复申请；
   - 不得将已获基金资助的项目重复申请；
   - 研究内容若已向其他渠道申请（处于受理/评审期），不得再申请自然科学基金；若已获其他资助，需在申请书中说明“资助情况+与本项目的区别与联系”。


### （三）典型科研不端案例（警示）
1. 人员替换重复申请：夫妻、课题组同事或师兄弟间，一方上年度申请未中，下年度更换申请人姓名提交相同内容；
2. 项目内容重叠：重点/面上项目申请书包含当年提交的面上/青年项目内容，或面上项目包含已获批青年项目内容；
3. 同一内容多人申报：1份申请书由多人同年以不同申请人身份提交；
4. 成果挪用：参与他人申请书撰写后，在对方放弃研究时，自行使用该申请书申请；
5. 外购申请书：从网上购买或通过其他渠道获取申请书用于申请。

**注**：基金委会对申请书进行查重，抄袭或重复申请将被严肃处理。


## 五、特殊项目申报要求
### （一）外国学者研究基金项目
#### 1. 项目分类与资助额度
| 项目类别 | 资助额度（每年） | 项目期限 | 起止时间示例 |
|----------|------------------|----------|--------------|
| 外国青年学者 | 20万元 | 1年/2年 | 1年期：2026.1.1-2026.12.31；2年期：2026.1.1-2027.12.31 |
| 外国优秀青年学者 | 40万元 | 1年/2年 | 同上 |
| 外国资深学者 | 80万元 | 1年/2年 | 同上 |

#### 2. 申请人条件
- 取得博士学位（需符合指南时间要求）；
- 资助期限内，每年在依托单位从事基础研究工作**不少于9个月**（2026年起执行，2026年入站博士后需确认入站时间是否符合）。

#### 3. 必备附件材料
| 附件名称 | 要求 |
|----------|------|
| 项目申报协议书 | 使用基金委模板，不得擅自修改；需正确填写“姓名+职称（博士后填‘无’）+国籍+研究期限”；由学院科研秘书统一申请盖章 |
| 聘用合同 | 需覆盖项目执行期；若申请时未签订或合同不符合要求，项目获批后提交计划书时需补充符合要求的合同（否则不予拨款或终止项目） |
| 伦理/安全材料 | 涉及科技伦理、生物安全、信息安全的，需按规定提供相关审查材料 |


### （二）合作创新研究团队项目
#### 1. 核心要求
- 学院/附属医院需审核申请材料的“真实性+完整性+合规性”；
- 资助期限内，申请人每年在依托单位从事基础研究工作**不少于6个月**（项目获批后执行）。

#### 2. 协议签署
- 需使用基金委“合作创新研究团队项目申报协议书”模板（不得修改），姓名需与系统一致，职称信息准确；
- 若申请人有国外全职工作单位，需出具“国外单位知悉证明”（避免后续纠纷）；
- 协议由学院科研秘书统一申请盖章。

#### 3. 必备附件材料
| 附件名称 | 要求 |
|----------|------|
| 聘用合同 | 需覆盖项目执行期 |
| 项目申报协议书 | 按模板填写，OA盖章（需学院科研秘书申请）；<br>- 已有聘用合同：上传合同，若合同未覆盖执行期，需主管科研副院长批示“项目获批后续签合同”；<br>- 无聘用合同：需学院与人事处沟通，主管科研副院长批示“项目获批后签订合同” |
| 其他材料 | 代表性论著、科技伦理/科技安全审查材料（如有） |
